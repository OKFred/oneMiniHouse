# 入库部署验收清单

这是通用检查清单，不声明任何实例已经通过。真实连接信息、消息 ID、时间窗口、读数及验收原文保存在被忽略的 `.local/` 或 `evidence/`。

1. 执行 `pnpm check` 和 `pnpm test`；构建候选镜像并保存配置、数据库定义及授权备份。
2. 选取明确的 UTC 半开时间窗口，用独立 MQTT 观察记录核对 SQLite 原文及各数据库的消息 ID、采样/读取时间、指标和 SHA-256。分别报告缺失、额外记录和差异，不能只比较总数。
3. 使用实际入库角色验证 SELECT/INSERT、限定站点 RLS、重复插入幂等以及同 ID 不同内容拒绝。验证 UPDATE、DELETE、TRUNCATE、DDL 和越界站点访问被拒绝；测试数据使用事务回滚。
4. 在隔离环境或获得维护窗口后分别中断每个目标连接，检查其他目标继续写入、待发标记跨重启保留、恢复后自动补写且清空队列。不要停止共享数据库或删除队列来制造成功。
5. 短暂停止入库服务后检查 MQTT 持久会话恢复；逐条核对补报保留原 ID 和原始观测时间。最终一致双写不等于跨数据库事务。
6. 从客户端验证云端 TLS 证书和主机名，不用池化器后端的 TLS 状态代替客户端检查。分别核对各目标新鲜度、拒绝数、永久失败和最后成功时间。
7. 验证全部已有展示类别、标签页和已启用分享页。使用 Grafana 实际只读账号检查限定视图可读、底表与内部兼容视图不可读，详见 [项目回归规则](../AGENTS.md)。

应用健康、容器健康、目标投递、真实数据库查询和页面展示分别记录证据；未完成的检查必须列出。恢复方法与保留期边界见 [README.md](README.md)。
