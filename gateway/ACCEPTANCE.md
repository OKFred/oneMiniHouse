# 网关部署验收清单

这是通用检查清单，不代表任何实例已经验收。实际设备、账号、消息 ID、读数、部署位置和截图保存到被忽略的 `.local/` 或 `evidence/`。

1. 执行 `pnpm check` 和 `pnpm test`，构建候选镜像，保存源码版本、镜像 ID 和配置备份。
2. 确认非 privileged、能力集、只读根目录、资源限制和数据卷符合部署要求。BlueZ 代理只暴露所需接口，不开放完整系统总线。
3. 用独立 MQTT 观察账号核对协议帧 CRC、解析结果、采样时间及消息 ID。验证发布账号不能订阅或发布其他网关主题，观察账号不能发布或读取其他网关。
4. 连续观测多个采样周期，检查成功数、错误数、队列、丢弃数和实际采样间隔。资源快照不能代替容量测试。
5. 在隔离环境或获得维护窗口后验证设备不可用、网络中断和进程重启。失败不得产生零值遥测；未确认消息及原始 ID 必须跨重启保留，恢复后按顺序补报。
6. 验证 retained state 不会被旧补报回退，并在部署主机重启后确认自动启动和新采样。
7. 更新前后回查同机已有服务。蓝牙网关、Modbus 网关和入库服务分别记录验收结果。

保存每项检查的时间窗口、输入、实际结果和未完成项。实时 MQTT 到达、历史入库和看板展示是不同验收边界；通过其中一项不能替代其余检查。操作与回退方法见 [README.md](README.md)。
